# dsh-deepseek-web

> 📌 **功能范围**：本插件仅通过悬浮球与侧边栏打开官方 chat.deepseek.com **网页面板**；在 DSH 中直接选 DeepSeek Web 模型对话的功能自 1.0.44 起已移除。
> 📌 **Scope**: This plugin only opens the official chat.deepseek.com **web panel** via a floating ball and the sidebar; in-DSH chat with a DeepSeek Web model was removed in 1.0.44.

See the repository README for install and security boundaries.

This package is a DeepSeek Harness plugin. It uses DeepSeek Web through a
compatibility layer, is not the official Open Platform adapter, and does not
bypass CAPTCHA/WAF or account access controls.
